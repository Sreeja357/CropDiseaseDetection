# 🌿 Deep Learning-Based Crop Disease Detection

## 📌 Overview
This project is a deep learning-based crop disease detection system that identifies diseases in crop leaves from images. It uses the DenseNet-121 model with transfer learning to classify multiple crop diseases accurately. The system supports early disease detection and helps improve agricultural productivity through AI-based analysis.

---

## ✨ Features
- Detects multiple crop leaf diseases from uploaded images
- Uses DenseNet-121 with transfer learning for classification
- Image preprocessing and data augmentation for improved accuracy
- Multi-class disease classification
- Performance evaluation using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix
- Supports smart agriculture and early disease detection

## 📂 Dataset
- Publicly available crop leaf disease dataset
- Images of healthy and diseased crop leaves
- Dataset split into Training, Validation, and Testing sets

---

## 🧠 Model
- Architecture: DenseNet-121
- Technique: Transfer Learning
- Optimizer: Adam
- Loss Function: Cross-Entropy Loss
- Evaluation Metrics:
  - Accuracy
  - Precision
  - Recall
  - F1-Score
  - Confusion Matrix

---

## 🚀 Project Workflow
1. Collect crop leaf image dataset
2. Preprocess and resize images
3. Apply data augmentation
4. Train DenseNet-121 using transfer learning
5. Evaluate model performance
6. Predict crop diseases from new leaf images

---

## 📊 Results
- Achieved approximately **94% classification accuracy**
- High Precision, Recall, and F1-Score across multiple disease classes
- Effective for early crop disease detection
